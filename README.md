# opencode-cleaner

A command-line tool to clean up OpenCode data.

Data directories are detected automatically from the installed OpenCode executable.

```sh
npx opencode-cleaner
```

![opencode-cleaner demo](assets/demo.gif)

## Requirements

Node.js 24.15.0 or later.

## Installation

```sh
npm i -g opencode-cleaner
```

## Usage

```sh
opencode-cleaner
```

Or run without installing:

```sh
npx opencode-cleaner
```
